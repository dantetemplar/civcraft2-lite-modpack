# CivCraft 2 Lite — Packwiz

Клиентская сборка Minecraft **1.21.1**, NeoForge **21.1.247**, Java **21**. Packwiz проверяет и устанавливает обновления перед каждым запуском игры.

## Установка в PolyMC / Prism / Freesm Launcher

1. Скачай архив для своего лаунчера: [Prism / Freesm](https://github.com/dantetemplar/civcraft2-lite-modpack/releases/download/v1.1.3.1-fix2.4/CivCraft2Lite-1.1.3.1-fix2.4-Prism-Freesm-Packwiz.zip) или [PolyMC](https://github.com/dantetemplar/civcraft2-lite-modpack/releases/download/v1.1.3.1-fix2.4/CivCraft2Lite-1.1.3.1-fix2.4-PolyMC-Packwiz.zip).
2. В лаунчере выбери **Добавить сборку / Add Instance → Импорт из ZIP / Import** и укажи скачанный архив.
3. В настройках экземпляра выбери **Java 21**. Архив выделяет игре 8 ГБ памяти; компьютеру нужно больше 8 ГБ общей RAM, чтобы оставалась память для системы.
4. До первого запуска установи шесть модов из списка ниже. Открой папку Minecraft нового экземпляра через лаунчер и положи JAR-файлы в `mods`. Не распаковывай сами JAR.
5. Запусти экземпляр **CivCraft 2 Lite (Packwiz)**. Установщик скачает остальные моды и настройки с официальных источников. Для первой установки нужен интернет; дождись завершения окна Packwiz.

Архив небольшой: он содержит настройки лаунчера и установщик, а не все моды. Запускай через лаунчер, не через двойной клик по JAR.

### Шесть файлов для однократной ручной установки

Авторы этих модов запретили автоматическую загрузку через CurseForge API. Они обязательны для сборки; мы не перезаливаем их на GitHub.

- [Easy NPC 7.6.0](https://www.curseforge.com/minecraft/mc-mods/easy-npc/files/8584598) — `easy_npc_bundle-neoforge-1.21.1-7.6.0.jar`
- [Ingenium API 1.0.1](https://www.curseforge.com/minecraft/mc-mods/ingenium-api/files/8444471) — `ingeniumapi-1.0.1-NEOFORGE-MC-1.21.1.jar`
- [Powered TFC 0.4.3](https://www.curseforge.com/minecraft/mc-mods/powered-tfc/files/8567698) — `poweredtfc-0.4.3.jar`
- [Spindles TFC 1.0.5](https://www.curseforge.com/minecraft/mc-mods/spindles-tfc/files/7729016) — `tfc_spindles-1.21.1-neoforge-1.0.5.jar`
- [TFC Debark 1.0.6](https://www.curseforge.com/minecraft/mc-mods/tfc-debark/files/7884000) — `tfc_debark-1.21.1-neoforge-1.0.6.jar`
- [TFC LumberJack 1.0.5](https://www.curseforge.com/minecraft/mc-mods/tfc-lumberjack/files/7884016) — `tfc-lumberjack-1.21.1-neoforge-1.0.5.jar`

Если исходная **CivCraft 2 Lite 1.1.3.1** уже установлена, эти шесть файлов можно скопировать из её `mods`. Переносить все старые моды не нужно: так можно случайно оставить дубликаты и несовместимые версии.

Если первый запуск сообщает `This mod is excluded from the CurseForge API`, закрой установщик, скачай указанный файл по ссылке, положи в `mods` и запусти ещё раз. Если в будущем изменится версия одного из этих шести модов, его снова потребуется скачать вручную.

## Обновления

После установки просто запускай экземпляр как обычно: Packwiz проверяет обновления перед игрой. Не используй обновление исходного CurseForge-пака поверх этого экземпляра и не обновляй моды по одному без согласования со сборкой.

Packwiz управляет модами, конфигурациями сборки, KubeJS и данными Millenaire. Изменения управляемых файлов могут быть перезаписаны. Сохранения `saves`, корневые `options.txt`, `servers.dat`, скриншоты и аккаунты не входят в пакет обновлений.

Старые версии **отслеживаемых Packwiz** модов удаляются при обновлении. Посторонние JAR, добавленные вручную, могут остаться: не держи две версии одного мода в `mods`.

Версии Minecraft и NeoForge задаются отдельно в лаунчере. Установщик запускается с `--multimc-folder .packwiz`; автоматическая смена загрузчика отключена. Prism/Freesm используют идентификатор NeoForge `net.neoforged`, PolyMC — `net.neoforged.neoforge`, поэтому ZIP-архивы различаются.

Если старый ZIP в Prism/Freesm сообщает «Не удалось скачать метаданные для net.neoforged.neoforge 21.1.247», закрой лаунчер и в `mmc-pack.json` в папке экземпляра (рядом с `instance.cfg`, не внутри `.minecraft`) замени только `"uid": "net.neoforged.neoforge"` на `"uid": "net.neoforged"`. Версию `21.1.247` не меняй. Затем открой лаунчер и запусти экземпляр. Для PolyMC эта замена не нужна.

URL обновлений: <https://raw.githubusercontent.com/dantetemplar/civcraft2-lite-modpack/main/pack.toml>. Используется HTTPS raw GitHub: у GitHub Pages аккаунта сейчас проблема с сертификатом пользовательского домена.

## Переход с существующего клиента

Самый безопасный вариант — импортировать ZIP как **отдельный экземпляр**, перенести только шесть файлов выше и сохранить старый экземпляр до проверки игры. Сохранения автоматически не переносятся; при необходимости копируй их отдельно с резервной копией.

Для подключения обновлений прямо к существующему **уже исправленному** экземпляру закрой Minecraft и лаунчер, затем из корня этого репозитория выполни:

```bash
uv run --no-project scripts/attach_instance.py "/путь/к/экземпляру"
```

Указывай папку с `instance.cfg` и `mmc-pack.json`, не вложенную папку `minecraft`. Скрипт проверяет Minecraft/NeoForge и наличие Dynamic Trees TFC 3.0.1, делает резервную копию конфигураций и подключает pre-launch-команду. Мод `DynamicTreesTFC-1.21.1-3.0.0-beta5.jar` перед этим должен быть удалён и заменён версией 3.0.1.

## Что исправлено

- Dynamic Trees TFC **3.0.1** вместо beta5: устранена причина исчезновения предметов из JEI.
- Квест на верстак принимает любой верстак TerraFirmaCraft через advancement.
- FTB XMod Compat **21.1.11** подключает открытие рецептов JEI из квестбука; версия подобрана под JEI **19.27.0.336**. Кликни предмет задания, затем предмет в окне **Valid items**.
- В FancyMenu включён режим сборки: панель редактора скрыта; уведомления об обновлениях Xaero’s Minimap / World Map отключены без смены версий модов.
- Configured **2.6.3** открывает настройки JEI в игре вместо сообщения об отсутствующем моде.
- TrashSlot **21.1.11** добавляет перемещаемую мусорку в инвентарь (переключение клавишей `T`, последнюю удалённую стопку можно забрать обратно). Для мультиплеера серверу также нужен TrashSlot и Balm; клиентский Packwiz сервер не обновляет. Чит-режим JEI не включён.
- FindMe **3.3.4** ищет предмет из инвентаря / JEI в ближайших контейнерах: наведи курсор и нажми `Y`. По умолчанию радиус — 8 блоков, подсветка — 30 секунд. Требуется на клиенте и сервере вместе с Architectury API. Клавишу можно изменить в настройках управления → FindMe; `Y` также используется Xaero. Поддержка нестандартных контейнеров зависит от их реализации.
- Серверная интеграция FindMe рекурсивно ищет во вложенных контейнерах: Small Vessel (включая глазурованные), Basket / Bundle, шалкерах, больших сосудах и бочках TFC. Проверяются предметы на полу (`V` / `tfc:placed_item`), сундуки, обычные контейнеры Minecraft, инвентари TFC и блоки с NeoForge ItemHandler (включая доступ только с отдельных сторон). Другие предметы-контейнеры поддерживаются через стандартные компоненты или NeoForge ItemHandler; произвольные собственные NBT-форматы без этого API не разбираются. Подсвечивается внешний блок-хранилище. Лимиты — 8 уровней вложенности и 2048 проверок стеков на блок за запрос; есть защита от циклов. Поиск учитывает настройку FindMe `IGNORE_ITEM_DAMAGE`, только читает содержимое и не добавляет дистанционное извлечение. Capability предмета запрашивается на копии стека. Обычные выброшенные предметы-сущности не входят в этот поиск.
- TFC Ruins **1.0.0** добавляет заброшенные постройки с добычей в новых чанках мира TFC. Primitive Creatures **2.7** добавляет первобытных существ и враждебных илладжеров; нужен на клиенте и сервере. Оба мода включены в Packwiz; существующие чанки не перегенерируются, настройки естественных поселений Millenaire не менялись.
- Server Waypoint **4.0.0** синхронизирует общие точки с сервером отдельно от личных точек Xaero. На сервере создан набор **CivCraft Shared**. Открыть менеджер: `/wp_gui` или правый `Shift`; список: `/wp list`. Игроки могут добавлять и редактировать точки; удаление, загрузка личных наборов и телепортация требуют прав оператора. Автоматическая замена личного набора Default и смена идентификатора мира отключены.
- Xaero’s Maps: Multiplayer+ **1.2.3** распространяет исследованную игроками карту через сервер; клиентам также нужен YACL **3.8.2**. Синхронизация пещер отключена, чтобы сохранить локальные слои пещер Xaero. Сервер проверяет поступающие чанки; скорость обмена ограничена. Личные карты находятся в `minecraft/xaero`, служебное состояние синхронизации — в `minecraft/xmmp`; они не входят в Packwiz.
- FallingTree **1.21.1.3** установлен только на сервере: ванильное дерево рубится целиком топором, прочность расходуется за каждое бревно. Удерживай `Shift`, чтобы рубить по одному блоку. Лимит — 128 брёвен, нужна естественная листва; деревья TFC, Dynamic Trees и других установленных модов исключены. Для одиночной игры клиентский Packwiz этот серверный мод не устанавливает.
- Включены предыдущие исправления скриптов и данных сборки.

Это **клиентская раздача**. Не применяй её к Exaroton: серверные и клиентские стороны всех остальных модов отдельно не проверены. Исправление открытия рецептов ставится на клиент и не требует изменения сервера.

[Отдельный ручной патч открытия рецептов без Packwiz](https://github.com/dantetemplar/civcraft2-lite-modpack/releases/download/v1.1.3.1-fix2.2/CivCraft2Lite-quest-recipes-client-patch.zip).

## Для сопровождения сборки

Установи CLI Packwiz, затем меняй пакет в этой папке, не в игровом экземпляре. После ручных изменений выполни `packwiz refresh`, проверь diff, сделай commit и push. GitHub Actions проверяет хеши и публикует индексированные файлы. Клиенты следят за веткой `main`, поэтому push изменений пакета запускает их распространение независимо от создания релиза.

Собрать новый ZIP лаунчера:

```bash
uv run --no-project scripts/build_launcher.py --launcher prism /путь/к/Prism-Freesm-Packwiz.zip
uv run --no-project scripts/build_launcher.py --launcher polymc /путь/к/PolyMC-Packwiz.zip
```

Оригинальная сборка: [CivCraft 2 Lite на CurseForge](https://www.curseforge.com/minecraft/modpacks/civcraft-2-lite). Авторство и лицензии модов и исходного контента принадлежат их авторам.
